# 스톡업 (StockUp)

1,000만 원 모의투자 · 실시간 시세 · 물타기 계산기 · 차트 게임을 한 손에 담은 모바일 퍼스트 주식 웹앱입니다.

> 실제 주문이 이뤄지지 않는 모의투자 서비스이며, 표시되는 시세는 학습용 예시 데이터입니다.

## 화면

- **모의투자** — 총 자산·평가 손익·보유 현금 요약, 자산 구성 바, 보유 종목 목록, 시세 시뮬레이션(±1~5%), 최근 매매
- **시세** — 코스피·코스닥·나스닥·원/달러 지수, 종목 검색, 전체/국내/미국/관심 필터, 스파크라인, 관심 등록, 빠른 모의매수
- **계산기** — 물타기(추가 매수) 계산기, 목표 수익률 계산기, 매매 기록
- **게임** — 봉차트 20일 실전 챌린지(양봉·음봉, 5일선, 거래량, 평단선, 수익률 등급) / 30초 실시간 단타

종목 상세 시트에서는 기간 탭(1일·1주·1달·3달·1년) 차트, 시가총액·52주 최고/최저·거래량, 매수/매도 주문 시트(수량 스테퍼, 10%·25%·50%·최대)를 사용할 수 있습니다.

## 기술

- React 18 + TypeScript + Vite 5 + Tailwind CSS 3
- 상태는 `localStorage`(`stockup:v1`)에 저장 — 보유 종목, 현금, 관심 종목, 매매 기록, 게임 최고 기록
- 모바일 퍼스트(최대 480px), 다크 핀테크 테마, Pretendard

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run preview
```
